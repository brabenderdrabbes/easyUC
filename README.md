# easyUC

FabricMod that improves the playing experience of UnicaCity


## Build

Install Java 21 first, then run:

```powershell
.\.gradle-local\gradle-8.14.3\bin\gradle.bat build
```

The main easyUC mod jar will be created in:

```text
build/libs/easyUC-1.0.8.jar
```

Put that jar into the mods folder of your NoRisk Client profile for Minecraft 1.21.10.
